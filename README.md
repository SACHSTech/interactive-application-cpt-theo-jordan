# Sticker Clicker

![Sticker Clicker Screenshot](https://i.ibb.co/60K1h2xy/Image-2026-06-08-at-12-41-PM.jpg)
> Ultra Rarity Sticker 

### Game Description
**_Sticker Clicker_** is an incremental simulator clicking game where you can _upgrade_ your sticker to the highest rarity! There are **8** total rarities, with each one **smiling** more and more. 

### User Interaction
_Clicks_ are added to the score counter after each click. Using said clicks, the user is able to **purchase** upgrades where the sticker rarity ascends to the **next level**, giving a predetermined multiplier. After the last rarity is reached, a **rebirth** option appears, which resets multipliers and clicks, but adds a **rebirth multiplier** which stacks upon itself each rebirth. The user can continue clicking and upgrading the sticker **indefinitely.**

### Limitations
- The multiplier and requirements text will go off-screen if the multiplier is larger than **4 digits**
- There is a limit to the amount of **maximum clicks**, being the java integer limit _(2,147,483,647)_

### Incomplete/Unadded Features
- **Powerups** --> Random powerups that would have a chance to appear each click and give temporary multiplier boosts
- **Autoclicker** --> A function to allow the screen to click itself
